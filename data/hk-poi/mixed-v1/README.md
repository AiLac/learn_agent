# 香港多类别 POI 检索语料

这套混合候选池有 **617 个地点**。它适合练习同地址消歧、活动描述召回、多个意图分别选点，以及回答前核验资料的适用范围。数据是 2026-11-09 取用的公开快照。

| 类别（命令行筛选值） | 地点数 | 可检索和查证的资料 |
| --- | ---: | --- |
| 自修室 `study_room` | 194 | 复用[原地点](../../hk-study-rooms/search-v2/places.json)及[79 张证据卡](../../hk-study-rooms/search-v2/evidence.json)，覆盖名录和部分场所的开放、设施与预约资料。 |
| [公园及动植物公园](venues/park.json) `park` | 123 | 设施类型、部分园地的细项、常规开放与工程例外。 |
| [体育馆](venues/sports.json) `sports` | 106 | 羽毛球、篮球、壁球、健身室等场地类型；部分记录有开放备注。 |
| [公众街市及熟食市场](venues/market.json) `market` | 88 | 食环署的商品/服务摊位类别、该快照的对应数量、街市与熟食中心各自的开放时间（如有列明）。 |
| [游泳池](venues/pool.json) `pool` | 46 | 部分场馆列明室内外泳池、训练池、家庭更衣或无障碍设施。 |
| [泳滩](venues/beach.json) `beach` | 42 | 海滩设施类别、部分场地的烧烤、淋浴与无障碍资料。 |
| [博物馆](venues/museum.json) `museum` | 18 | 名称、地址、官网；太空馆、艺术馆和科学馆另有官网展品或馆藏资料。 |

## 一组同楼、不同意图的题

从仓库根目录运行，入门实验的默认数据仍是 36 条。

```powershell
py -3 examples/day-01/run.py "花园街" --dataset mixed --limit 8
py -3 examples/day-01/run.py "花园街" --dataset mixed --category sports
py -3 examples/day-01/run.py "月球" --dataset mixed --category museum
```

第一条应命中花园街公共图书馆学生自修室、花园街体育馆、花园街街市。第二条只在 106 个体育馆中查，返回其中的体育馆。第三条可由展览资料找到香港太空馆。这里的 Java 程序演示字面子串匹配，结果按 ID 稳定排序；自然语言意图、混合召回与重排是学员要对照实现的部分。

| 用户想做什么 | 期望定位 | 哪条资料才有用 |
| --- | --- | --- |
| 在花园街温书 | 自修室 E06 | 引用学生自修室的时刻表。 |
| 在花园街找地方打羽毛球 | 花园街体育馆 | 该馆设施列有羽毛球场，不能据此保证有可订时段。 |
| 在花园街买鱼，晚上再吃熟食 | 花园街街市及其熟食中心 | 商品分类与场馆时段分开看，市场部分和熟食中心列出不同的常规关门时间。 |

另一个反例是同在尖沙咀梳士巴利道 10 号的香港太空馆和香港艺术馆。仅凭地址无法判断“想看月球、火星互动展品”的用户应去哪家。详见 [12 道混合 POI 开发题及参考证据](dev-cases.json)。同一地址的改写按 `group` 一起划分；开发题的答案仅用于评分。

## 数据结构与复现

[manifest.json](manifest.json) 将已有 194 条名录与 6 份新增分类文件组合起来，路径均相对于清单。每份新增数据内的 `records` 有地点 ID、类别、简繁名称、英文名、地区、地址、WGS84 经纬度和嵌入的 `evidence`。证据用 `source_ref` 指向清单的来源项并带原始行号或市场名；另行查证的展品卡直接写 `source_url`。新增 423 个地点对应 427 张记录或专题卡，部分卡只支持地点身份。简体字段由原始繁体字段经 ICU 转写并清理格式，展示原名可使用 `name_tc`。

清单包含来源目录、实际下载 URL、原始内容的 SHA-256、下载日期、原始行数和整理后的场馆数。公共市场按原市场名和地区汇总商品，822 行商品记录对应 88 个市场；同一地点的商品行不作为独立 POI。公园源中的两行“灣仔峽公園”归到一个场馆，分别保留两个来源行的设施证据和地址。不同用途的同楼地点各保留其 ID。跨类别对照地区时，将原市场地区“旺角/油尖”归到油尖旺、“粉岭”归到北区、“将军澳”归到西贡；变化处保留 `source_district`。坐标表示场馆参考点，只宜算直线距离。

名录收录不代表此刻开放。未提供的时段保留未知，已列的清洁、分区、季节及工程关闭备注不能截掉。摊位数无法反映实时营业或库存；泳滩设施不能证明水质或当日救生服务；馆藏资料也不保证某件作品当日展出。生产规模、线上热度和真实用户查询分布须另行验证。
