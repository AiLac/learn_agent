# 多条分支都按时的联合概率

甲乙两类取证并行，所有结果都返回才能完整比较。
先求全体满足阈值的概率，再取补集得到至少一个过期的概率。
只在独立分支假设下相乘。
共享模型配额可能使它们相关，不含最终模型生成。

## 先解决一个具体问题

**十个接口各有 99% 的按期率，整条请求也有 99% 吗？**

若独立且必须等全体，概率取乘积。若共用配额，独立假设又会失效。
迁移到“第一个可用即可返回”的策略前，要确认用户允许缩小交付义务。


先从具体的低档设定开始：甲读取数取 1个、乙读取数取 1个、甲按期率取 95%、乙按期率取 90%。
三个结果依次是甲全组按期 95%、两组均按期 85.5%、至少一路过期 14.5%。
先手算这个起点，读完后再把另一个输入切到高档，这样能知道数字变化时究竟改变了哪个假设。

## 先写清输入边界和三个观测量

用 a 表示甲读取数，取 1个 或 5个，这两点是用于隔离因果影响的教学输入。

用 b 表示乙读取数，取 1个 或 3个，这两点是用于隔离因果影响的教学输入。

用 c 表示甲按期率，取 95% 或 99%，这两点是用于隔离因果影响的教学输入。

用 d 表示乙按期率，取 90% 或 98%，这两点是用于隔离因果影响的教学输入。

「甲全组按期」的计算式为 `100*(c/100)**a`，按业务量展开是 `100×(甲按期率/100)^甲读取数`，输出单位为%。

「两组均按期」的计算式为 `100*(c/100)**a*(d/100)**b`，按业务量展开是 `100×(甲按期率/100)^甲读取数×(乙按期率/100)^乙读取数`，输出单位为%。

「至少一路过期」的计算式为 `100*(1-(c/100)**a*(d/100)**b)`，按业务量展开是 `100×(1-(甲按期率/100)^甲读取数×(乙按期率/100)^乙读取数)`，输出单位为%。

公式中 ceil 与 floor 分别向上、向下取整，% 在表达式中作取余，** 为乘方，三元条件按“条件 ? 成立值 : 其他值”读取。展示数值最多保留三位小数，比较和反推采用未舍入值。
