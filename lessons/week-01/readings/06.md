# 开放区间够不够完成一次到访

用户到达时仍在开放，不一定来得及待满要求的时间。
采用同一天、同一时区的模拟分钟数，分别计算入场、可用窗口和离开余量。
已过早上开门时间，允许恰在截止时离开。负余量表示无法满足完整停留。

## 先解决一个具体问题

**用户到得及进去，就代表能学习一小时吗？**

这是两个命题。
先以同日同区的模拟绝对分钟判可入场，再比较整个停留区间能不能被包含。修改入场缓冲可能只改变第二个判断。


先从具体的低档设定开始：到达分钟取 1040分钟、常规截止取 1080分钟、入场缓冲取 0分钟、要求停留取 30分钟。
三个结果依次是最早开始 1040分钟、可用时长 40分钟、完成余量 10分钟。
先手算这个起点，读完后再把另一个输入切到高档，这样能知道数字变化时究竟改变了哪个假设。

## 先写清输入边界和三个观测量

用 a 表示到达分钟，取 1040分钟 或 1130分钟，这两点是用于隔离因果影响的教学输入。

用 b 表示常规截止，取 1080分钟 或 1200分钟，这两点是用于隔离因果影响的教学输入。

用 c 表示入场缓冲，取 0分钟 或 20分钟，这两点是用于隔离因果影响的教学输入。

用 d 表示要求停留，取 30分钟 或 75分钟，这两点是用于隔离因果影响的教学输入。

「最早开始」的计算式为 `a+c`，按业务量展开是 `到达分钟+入场缓冲`，输出单位为分钟。

「可用时长」的计算式为 `max(0,b-a-c)`，按业务量展开是 `max(0,常规截止-到达分钟-入场缓冲)`，输出单位为分钟。

「完成余量」的计算式为 `b-a-c-d`，按业务量展开是 `常规截止-到达分钟-入场缓冲-要求停留`，输出单位为分钟。

公式中 ceil 与 floor 分别向上、向下取整，% 在表达式中作取余，** 为乘方，三元条件按“条件 ? 成立值 : 其他值”读取。展示数值最多保留三位小数，比较和反推采用未舍入值。

```mermaid

    v0["到达分钟"] --> m0["最早开始"]
    v0["到达分钟"] --> m1["可用时长"]
    v0["到达分钟"] --> m2["完成余量"]
    v1["常规截止"] --> m1["可用时长"]
    v1["常规截止"] --> m2["完成余量"]
    v2["入场缓冲"] --> m0["最早开始"]
    v2["入场缓冲"] --> m1["可用时长"]
    v2["入场缓冲"] --> m2["完成余量"]
    v3["要求停留"] --> m2["完成余量"]
```
